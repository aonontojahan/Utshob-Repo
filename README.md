## ✨ Features of the Portfolio Web App

- **🎨 Modern Glassmorphism Aesthetic**: Custom-built with CSS variables, ambient glowing neon accents, smooth scrolling, and dynamic responsive cards.
- **💻 Embedded Terminal CLI (`utshob-cli`)**: An interactive terminal window accessible via the navbar or floating action button. Visitors and recruiters can type commands (`help`, `skills`, `projects`, `experience`, `contact`, `hire`, `clear`).
- **📄 LaTeX Resume Viewer Modal**: Highlighting the original LaTeX source code with a single-click copy functionality and download preview.
- **🔍 Live Skills Matrix & Search**: Real-time filtering and search bar across technical skill tags.
- **📅 Dual-View Experience & Education Timeline**: Interactive tab switcher displaying professional roles at **3S Software Limited** and **SkyTech**, along with academic achievements from **IUBAT** (B.Sc CSE - CGPA 3.10).
- **🌗 Light & Dark Theme Toggle**: Seamless theme switching with persistent local storage state.

## 🚀 Running Locally

To run this portfolio locally on your machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/aonontojahan/Utshob-Repo.git
   cd Utshob-Repo
   ```

2. **Launch a local HTTP server**:
   Using Python:
   ```bash
   python -m http.server 8080
   ```
   Or using Node `serve`:
   ```bash
   npx serve .
   ```

3. **Open in browser**:
   Navigate to `http://localhost:8080/`
